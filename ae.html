03After Effects

让静帧动起来

画画的人学 AE，最先要改掉的是「一帧好看就够了」的惯性。动效是时间的构图： 什么时候进入、什么时候停留、什么时候收住，比加了几个特效重要得多。 这一页记录我的学习顺序、常用的表达式，以及真正会背下来的快捷键。

合成与预合成 关键帧曲线 表达式 导出规范

01 / Roadmap

我的学习顺序

每一阶段都以「做出一个能给人看的东西」结束。

  1. 01

    合成、图层与时间轴

    先搞清楚合成不等于画布、预合成相当于打包、时间轴上的层级是从上往下叠的。这一阶段只做一件事：把一张图分层，做视差位移。

    CompPre-compose视差
  2. 02

    关键帧与速度曲线

    所有「高级感」都来自缓动。F9 只是起点，真正要做的是进曲线编辑器，把入点拉慢、出点收住，让动作有重量。

    F9Graph Editor缓动
  3. 03

    表达式与自动化

    重复的动作交给代码：抖动、循环、自动贴合文字。表达式不是炫技，是为了改一个参数就能整体重排。

    JavaScriptwiggleloopOut
  4. 04

    文字动画与节奏

    用 Range Selector 做逐字入场，配合音效卡点。文字动效的难点从来不是效果，是让它跟着呼吸走。

    AnimatorRange Selector
  5. 05

    跟踪、合成与输出

    Mocha 跟踪、绿幕抠像、色彩统一，最后按用途导出：交付用 H.264，留档用 ProRes。工程整理比渲染更花时间。

    MochaKeyingProRes

02 / Expressions

四个够用的表达式

按住 Alt 点属性前的秒表粘贴进去即可，复制按钮已就位。

wiggle · 位置 
// 温和的手持感，别超过 2 的振幅
var freq = 1.2;   // 每秒抖动次数
var amp  = 12;    // 振幅（像素）
wiggle(freq, amp);
loopOut · 循环 
// 首尾无缝循环，适合待机动作
loopOut("cycle");

// 只循环最后 24 帧，前面留给入场
loopOut("cycle", 24);
sourceRectAtTime · 贴合文字 
// 放在「矩形路径 → 大小」上，底板跟着文字变宽
var title = thisComp.layer("Title");
var padX = 40;
var padY = 18;
var r = title.sourceRectAtTime(time, false);
[r.width + padX * 2, r.height + padY * 2];
linear · 数字递增 
// 源文本：从 0 数到目标值
var target = 128;
var dur    = 1.5;  // 秒
var v = linear(time, 0, dur, 0, target);
Math.round(v).toString();

别急着抄：先把表达式里的数字改一遍，看画面怎么变。理解了参数，才算真的会用它。

03 / Shortcuts

真正会背的快捷键

选中图层再按，左手基本不用离开键盘。

快捷键作用
PSRTA位置 / 缩放 / 旋转 / 不透明度 / 锚点
U只显示已有关键帧的属性
F9Easy Ease，给选中关键帧加缓动
Shift + F3打开曲线编辑器，调速度曲线
[ / ]图层入点 / 出点对齐到播放头
Ctrl + Shift + D在播放头处拆分图层
Ctrl + Shift + C预合成选中图层
Ctrl + Shift + A取消选择全部图层
Ctrl + Alt + T启用时间重映射
Ctrl + K打开合成设置
M / MM蒙版路径 / 全部蒙版属性
B / N设置工作区起点 / 终点

04 / Export

导出设置

同一个工程，三种用途，别用同一套参数糊过去。

发布用

H.264，1080p，目标码率 12～20 Mbps。平台会二次压缩，源文件别给太低。

MP4 · H.264

留档用

ProRes 422 HQ 或 PNG 序列。文件大，但二次调色和剪辑不会掉画质。

ProRes · 序列

网页动图

短循环优先 WebM，体积小、透明度友好；必须兼容老环境时再退回 GIF。

WebM · GIF
