01 / Story

我在做什么

三条线互相喂养：图像给我审美，动效给我节奏，代码给我工具。

画画这件事

用 NovelAI 做底图，再靠提示词、构图与后期一点点推到想要的样子。 我关心的不是「一键出图」，而是怎么把脑子里的画面稳定地复现出来。作品主要发在 Pixiv，也接约稿。

Pixiv · 约稿中

写代码这件事

从脚本和小工具开始，一路写到这里：B 站推送、Pixiv 代理、这个站点。 现在更多是 vibe coding —— 我负责想清楚要什么，AI 负责把它写出来，我再逐行看懂、改到满意。

GitHub · 开源

02 / Path

学习路径

不追求速成，按能做出东西的顺序推进。

  1. Now · 打底

    把静态画面做出节奏

    AE 里练关键帧与曲线，先学会让一张图「动得合理」，而不是堆特效。

  2. Now · 扩展

    进入三维空间

    Blender 从建模和打光开始，目标是能把角色放进一个有体积感的场景里。

  3. Ongoing · 工具化

    让 AI 承担重复劳动

    用 vibe coding 把想法当天做成可用的页面、脚本和工作流，减少「想到了但没做」的损耗。

  4. Next · 合流

    把三条线接起来

    插画 → 分层 → AE 动效 → Blender 场景，最后用代码把整个流程串成可复用的管线。
