04Blender

给角色一个
可以被旋转的世界

画了两年二维，最想补的是「空间」。Blender 对我的意义不是做写实渲染， 而是能随手搭一个场景、摆一盏灯，看看光从侧面打过来时，画面会变成什么样。 这一页是建模、材质与渲染的练习记录，也包括几个省时间的脚本。

建模 材质与灯光 Cycles Python / bpy

01 / Roadmap

从方块开始

按「能出图」倒推，先学打光和构图，再回头补拓扑。

  1. 01

    视图导航与物体操作

    中键旋转、Shift+中键平移、滚轮缩放；G/R/S 三件套先练到盲操。这一关过了，后面才不别扭。

    NavigationG / R / S
  2. 02

    方块建模与硬表面

    从立方体挤出开始，用环切加结构线、倒角收边。目标不是高模，是形体干净、比例可信。

    ExtrudeLoop CutBevel
  3. 03

    材质、UV 与贴图

    Principled BSDF 的粗糙度和金属度先玩熟，再学用节点混出插画质感。UV 展开只求不拉伸。

    ShaderUVNode
  4. 04

    灯光与构图

    三点布光、HDRI 环境光、区域光的软硬对比。灯打对了，普通模型也能出片。

    HDRIArea Light三点布光
  5. 05

    渲染与合成

    EEVEE 用来快速试错，Cycles 出终图。分层渲染（Object Index / Cryptomatte）后进 AE 调色。

    EEVEECyclesCryptomatte

必须形成肌肉记忆的键

03 / Scripts

常用的小脚本

重复操作超过三次，就该写成脚本了。

Python · 批量改名 
import bpy

prefix = "BF_"
for obj in bpy.context.selected_objects:
    if obj.name.startswith(prefix):
        continue
    obj.name = prefix + obj.name
    obj.data.name = obj.name
Python · 渲染设置 
import bpy

scene = bpy.context.scene
scene.render.engine = "CYCLES"
scene.cycles.samples = 256
scene.cycles.use_denoising = True
scene.render.resolution_x = 1920
scene.render.resolution_y = 1080
scene.render.image_settings.file_format = "PNG"
Shell · 无界面渲染 
# 批量渲染整段动画，-a 表示 render animation
blender -b scene.blend \
  -o //frames/f_#### \
  -F PNG -a
Python · 应用全部变换 
import bpy

bpy.ops.object.select_all(action="SELECT")
bpy.ops.object.transform_apply(
    location=False,
    rotation=True,
    scale=True
)

04 / Resources

在用的资源站

免费素材优先，能商用且署名清楚的才进项目。

Poly Haven

HDRI、材质、模型全免费，CC0 授权。打光找不到感觉时，先换一张环境图。

polyhaven.com

BlenderKit

直接装在 Blender 里的资产库，材质和模型一键拖进场景，适合快速搭景。

blenderkit.com

官方教程

想系统过一遍基础时看官方，比二手教程少踩版本差异的坑。

blender.org

一个习惯：每个练习都存两个版本 —— 一个继续改，一个封存。封存的那份用来对比，进步才看得见。
